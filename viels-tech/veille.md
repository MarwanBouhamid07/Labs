# veille technologie :

La veille technologique consiste à rechercher et suivre régulièrement les nouvelles technologies pour rester à jour.

----

# Ses objectifs :

Découvrir les nouveautés.

Apprendre de nouvelles compétences.

Améliorer son travail.

Choisir les bons outils.

----

# Comment faire une veille technologique ?

Pour faire une veille technologique, il faut suivre 4 étapes :

**Rechercher :** chercher des informations sur les nouvelles technologies.

**Suivre :** consulter régulièrement des blogs, des tutoriels et des documentations.

**Tester :** essayer les nouveaux outils dans des petits projets.

**Partager :** résumer et partager les informations importantes avec son équipe.

----

# Les étapes : Rechercher → Suivre → Tester → Partager.

*Exemple :* Un développeur découvre Laravel, consulte sa documentation et réalise un petit projet pour apprendre à l’utiliser.
