# Lab 3 : Préparer l’environnement de développement sous Windows

## 1. Objectif

L'objectif de ce lab est de préparer un environnement de développement Web sous Windows en installant et en configurant Visual Studio Code ainsi que les outils nécessaires à la programmation.

## 2. Installation de Visual Studio Code

Visual Studio Code est un éditeur de code source qui permet de développer des applications Web. Il prend en charge plusieurs langages, notamment PHP, HTML, CSS et JavaScript.

## 3. Installation des outils nécessaires

Les outils utilisés pour préparer l'environnement de développement sont :

- **PHP :** pour exécuter les scripts PHP et les applications Laravel.
- **Composer :** pour gérer les dépendances PHP.
- **Git :** pour suivre les modifications du code source.
- **Node.js et npm :** pour gérer les dépendances JavaScript et préparer les ressources front-end.
- **Un navigateur Web :** pour tester les applications développées.

## 4. Configuration de Visual Studio Code

Des extensions adaptées au développement Web peuvent être installées, notamment PHP Intelephense et Laravel. Elles facilitent l'écriture du code, l'autocomplétion et la détection de certaines erreurs.

## 5. Vérification de l'environnement

La commande `php -v` permet de vérifier la version de PHP. La commande `composer --version` vérifie Composer, tandis que `git --version` vérifie Git.

La commande `php artisan --version` permet de vérifier que Laravel est accessible depuis le projet.

## 6. Conclusion

La préparation de l'environnement de développement permet de disposer des outils nécessaires pour créer, exécuter, tester et maintenir des applications Web. Visual Studio Code facilite l'écriture du code, tandis que PHP, Composer et Git contribuent au développement et au suivi du projet.
