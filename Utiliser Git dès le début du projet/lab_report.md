### Tâche : Initialisation d'un dépôt Git

**Objectif :** Mettre en place le suivi des modifications du projet Laravel dès le début du développement.

**Étapes réalisées :**
1. Initialisation du dépôt Git avec `git init`.
2. Vérification de l'état du dépôt avec `git status`.
3. Ajout des premiers fichiers avec `git add .`.
4. Création du premier commit avec `git commit -m "Initial commit"`.
5. Vérification de l'historique avec `git log -1 --oneline`.

**Résultat attendu :** Le dépôt Git est initialisé, les premiers fichiers sont enregistrés dans un commit et l'état du dépôt est vérifié.### Tâche : Initialisation d'un dépôt Git
